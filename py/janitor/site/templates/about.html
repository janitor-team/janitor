Source Code

The Janitor itself is written in a mix of Python and Rust, using the following libraries and services:

  • The style for the website is based on Alabaster 0.7.8 theme for sphinx.
  • Breezy provides abstractions over the version control system (Git, Bazaar, Mercurial & Subversion) and the supported hosting platforms (GitHub, GitLab, Gitea & Launchpad).
  • Silver-Platter ties this all together; it manages branches, invokes codemods and pushes back or creates merge proposals.
  • lintian-brush applies the actual fixes for the lintian-fixes campaign.
  • ognibuild detects and installs a codebase's build dependencies.

The source code is hosted on GitHub.
